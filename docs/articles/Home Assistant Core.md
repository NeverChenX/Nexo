# Home Assistant Core

- GitHub：<https://github.com/home-assistant/core>
- 收录时间：2026-04-21
- 类型：开源家庭自动化平台核心项目

## 项目简介

Home Assistant Core 是一个开源家庭自动化平台核心项目，强调本地控制和隐私优先。

## 亮点

- 支持大量智能家居设备与协议集成，可以把不同品牌设备统一到一个自动化系统中。
- 本地优先架构减少对云端的依赖，在稳定性、可控性和隐私保护方面很有优势。

## 适合人群

- 智能家居爱好者
- 注重隐私的家庭用户
- 家庭自动化开发者与集成商
