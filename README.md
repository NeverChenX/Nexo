# Nexo

Nexo is a lightweight personal wiki and knowledge document manager built with Next.js.
It gives you a fast, local-first workspace for writing, organizing, previewing, and sharing notes and documents.

## Features

- Markdown-based wiki pages
- Document tree navigation
- Live editor and preview workflow
- Local data storage for personal knowledge bases
- Shareable links for selected pages

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
