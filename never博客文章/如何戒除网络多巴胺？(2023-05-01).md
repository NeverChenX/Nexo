# 如何戒除网络多巴胺？(2023-05-01)

Owner: Never

我也曾是手机成瘾重度患者，后来慢慢成功戒掉了，以至于到现在自己宁愿发发呆散散步，也不愿意把大把的时间花在社交媒体上。

那我是如何做到的呢？这篇文章核心观点，其实是写在5年前，至今依然没有改变。

想要解除网络多巴胺，其实只有唯一解：**删除那个耗费你时间的APP。**

游戏、抖音、快手、小红书、知乎...可以开启手机使用统计，看看哪个APP消耗你生命最多，然后逐渐删除，直到自己的生活没有虚度光阴。

你可能会有疑惑，为什么除了这个办法，其他的方法都会失败？

假设你3个月后有一场重要考试，你明知道这件事很重要，可是你当前又深陷沉迷短视频的内容无法自拔，于是你的大脑开始消耗意志力在进行对抗，**也许你可能会战胜个1、2次，但是意志力有时候是非常薄弱的，你的大部分都会失败。而且，每次失败都会养成更深的“网络多巴胺”回路，时间一长，从而无法自拔。**

更不要提，你的对手是什么人？

但凡是一个超级APP的背后，都是有一群清北，211，985高科技人才组成的智囊团，考核这个团队的目标只有一个：怎样令你上瘾，这样好消耗你的时间，赚取更多的广告费。而你只是一个普通人，怎么可能拼得过？

所以，这里有个结论，**任何企图减少刷手机的行为，都是靠不住的。**

在《如何想到又做到》这本书中，提到一个类似的科学实验：在对戒烟的人群中，最有效的戒烟策略是扔掉家中所有的烟草制品。

书中给出的解释：删除App、扔掉烟草制品，这种行为只要一狠心，**还是非常容易执行的**。但如果你通过克制自己吃甜食？注定会失败的。

**删除手机应用，彻底隔离，才是最佳解决方案。**

接下来你可能会有一些其他的疑惑，我将根据自己的经验，做出一些解答。

# 问题二：如何需要社交媒体查找资料怎么办？

比如说你抖音上瘾。但有时候又有工作需要上抖音查找资料怎么办？

下载APP后，查找资料，然后立刻删除！

这样，还有个好处，能够非常明确自己的目标。

# 问题三：进行到一半，根本停不下来怎么办？

我给出的答案是：玩到吐。

就拿我自己来说，我是个“强迫结尾患者”。就是一件事，我必须要知道结果，否则就会特别难受。

刷手机也是一样。

有一段时间，我特别迷恋吃鸡游戏，后来我就给自己定了一个目标，我每天都会拿出来至少8个时间，打上超级王牌（一个段位）。

然后，那段时间，没日没夜的玩，终于在20天后成功晋级，然后就把这个游戏删了，以后再也没有碰过。

不过，也要注意，不要轻易的开始一个事物。

比如说，我轻易不敢看《火影神者》这类的动画片，因为有好几百集，我知道自己开始了，就肯定停不下来，所以一集都没有看过。
