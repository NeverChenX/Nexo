# 中国经济什么时候会恢复？（2024-12-19）

Owner: Never

我们从经济三驾马车出发，来进行讨论。

# 外贸

首先是外贸，目前世界经济下行，全球各国普遍转右，可以预见的是各国均会出现不同程度的贸易保护主义。发达国家保留了金融和高端制造业，把低端制造业留给了中国，其他地方作为消费国，这是过去几十年这个世界的经济架构。而由于中国的技术不断积累，开始染指金融收割和高端制造业，这必然会遭到欧美等发达国家的普遍围猎。

可怕的是，目前看不到任何缓和迹象，目前整个世界的格局其实就是中美争霸，在经济下行阶段这种对抗将会越来越明显，可以预见的是特朗普这个任期之内，将不会出现任何好转。

# 投资

其次是投资，目前按照官方数据，中国政府的负债率只有67.5%，远少于发达国家的平均负债率118%，官方一直在强调，还有较大的杠杆空间。可这真的能解决问题吗？在中国监管制度缺失的情况下，投资并不是为了追求收益，而是某个领导的决策，这里面注定会产生大量的无效投资和腐败问题，会进一步导致贫富差距。别说是中国，哪怕就算是灯塔美国，在军方不断开支增加的情况下，也会出现9w美金一包螺丝。

无论是中国还是美国，政府每一次的扩大债务，都会造成贫富差距的进一步增加。财富的衡量是相对的，原来我有100块，你有1000块，我的消费会变得谨慎，放水之后我的财富变成200块翻了一倍，你的财富缺变成了1w块，翻了10倍。虽然我的财富收入增加了，可最终的实际却是减少了，导致我越来越不敢消费。

更不要提，政府加杠杆最终还是要投资，可是投什么呢？那些见效快的，在过去10年早已经被投完了，那些见效慢的领域，短期内也无法解决当下的问题。

所以，举债加杠杆就像是给病人吃止痛药，本质上是治标不治本，也许能缓解当下的问题，但问题根本没有解决，而且还给未来埋下了隐患。不过，按照中国的决策，一般不会考虑未来，每次都是头痛医头，脚痛医脚。所以这次未来大范围举债其实是不可避免了，这时候可以在资产比较便宜的时候，持有一些股权类资产，因为未来通胀不可避免。

# 消费

最后是消费。目前中国家庭占GPD的负债率已经到达62%，发达国家的占比为70%，表面上我们还有8个点的负债空间。可别忘记，发达国家的保障十分健全，就连润人讲师每天都能变着花样吃不同的东西。而我们的保障可以说十分不健全，本来就没钱的情况下，还要被某些有权力的人分走一部分，比如廉租房外面停着的都是豪车。东北最高的低保人员只能领取到每个月500块，连维持生存都不够。

所以62%的负债率已经是极限了，从储蓄层面去影响消费几乎没有希望。

另外一个影响消费的因素是对未来的信心，由于中国人绝大部分的资产都在房子上，所以房子未来的走势就会影响消费。那未来中国房子走势如何？坐一趟长途高铁就知道了，你就会看到沿线还有多少正在建设密密麻麻的房子，最保守的估计消化这些库存就需要几年时间，更不要提人口增量急剧减少，未来对房子的需求直线下降。就连官方的目标都是起跌回稳。注意，能稳住就不错了，就别指望上涨了。所以从消费这条路，看中国经济也是行不通的。

所以总结就是，未来4年也许中国会通过政府加杠杆的方式缓解中国经济问题，但却会埋下更大的隐患，治标不治本。

# 解决方案

那中国经济一路下滑，就没有路了吗？其实还真有，目前就一条路：**公平分配！**

就这四个字，中国过去几十年分配都是不公平的，伴随着互联网的发展信息变得越来越透明，以及人们越来越清醒，已经开始逐渐到意识到这个问题。

不公平是吧？上海和东北的生育率直接下降到0.6，比韩国还要低。

日本哪怕经历了失去的30年，依然还能维持1.2的生育率。为什么？就是因为日本社会相对来讲是很公平的。一旦收入开始变得公平了，人们对未来的预期就会改变，消费和生育率自然就上去了，经济一好，股市也自然就会好，就这么简单。现在中国，还妄想着靠信息差，来保持不公平分配的方式，可以说一去不复返了。
