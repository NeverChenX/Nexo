# 为什么现在年轻人承受能力差？（2024-03-13）

Owner: Never

<aside>

</aside>

最近在知乎上看到这个话题，我特别想聊聊我的观察与思考。

# 嫉妒

我刚上初一那年入冬，在东北农村那时候已经很寒冷了，所以家长都会给孩子制作一双：二棉鞋（介于棉鞋和普通鞋子之间），用于保暖。上学的时候，几乎每个孩子脚下，清一色都穿着妈妈制作的棉鞋。

可是有一天下课，我看到有一帮同学围着一个人在讨论什么，我凑近一瞧，原来是中间那个人穿着一双崭新的贵人鸟的旅游鞋，大家都在针对他那双旅游鞋进行夸赞。

那是我有生以来第一次体会到什么是：羡慕和嫉妒。

因为我小时候太穷了，常年穿着妈妈手工制作的鞋子，突然一双雪白的旅游鞋，让我产生了从心底的羡慕和嫉妒，以至于20年以后，我依然对那个场景历历在目。

而现在，不要说13岁的初中生了，就是现在上幼儿园的孩子，有时候都会说：你知道我爸爸开的是宝马吗？我衣服可贵了，你弄脏了根本赔不起。等等诸如此类的话语。

还有另外一个很重要的因素，信息的发达。

我16岁第一次进到城市里，结果在小区里面迷了路。没错，是小区里。因为我压根没见过城市的样子，没有见过那么多高楼大厦。不知道还有公交车的存在，甚至公交车还可以刷卡都令我感到吃惊。16岁以前，我一直都生活在信息闭塞的农村，我以为镇子上的二三层小楼，就是整个世界的样子。

可现在的年轻人呢？从小就可以通过智能手机知道，原来这个世界还有几千块一晚的酒店，高端的餐厅，名贵的跑车，华丽的生活…而自己的生活呢？不能说是地狱，也处在社会的底层。

这两者导致了，

不患寡而患不均，导致羡慕、嫉妒、自卑这种思想，如果很早就刻在心智还没有成熟的年轻人身上，而这注定是一场十分沉重的打击。

这种自卑下的打击，可以说影响一个人的一生都毫不为过。

不要说十几岁的青少年了，就是成年人都多少被击溃的？在一线城市身边得抑郁症的人比比皆是。

以前的叛逆，是叛逆父母的掌控，现在年轻人的叛逆，是叛逆生活的不公。

# 社交和娱乐

东北农村的教育是非常落后的，不过也有一个好处，给了少年时期的我大把的娱乐时间。比如，冬天的时候，因为太寒冷，我们下午3点就放学了，放学回家就是玩。

我和村子里的小伙伴们，小学同学，初中同学，都住在不远处，认识长达几十年，虽然现在联系的少了，但是在少年时期那种友谊带来的快乐是无法想象的。

可以说，农村的孩子虽然接受了落后的教育，但是都拥有一个快乐的童年。而一个快乐的童年，真的是可以治愈一个人的一生。这也是我发现，我身边的同龄人，几乎都没有心理问题。

可现在的孩子们呢？

我有一次去姐姐家（注重教育的学区房），我观察到，他们小区的孩子，下个楼玩耍的时间，都要脖子上套一个类似于播放器的东西来听英语。

你以为是个例？不...几乎每个孩子都一样，那一刻我突然觉得这是一件非常悲哀的事情。有一种犯人出去放风时间，还要带着枷锁的感觉。

而且，我观察到我外甥，几乎没有固定的玩伴，半固定的也就1-2个人，导致我外甥没办法很好的社交，只能自娱自乐。

社交，对一个人是十分重要的，哪怕是在监狱和军队，这种严格作息规律的地方也需要社交。否则为什么惩罚措施是：关禁闭？

如此繁重的学习压力，又加上如此的孤独感，人的心理怎么可能不出问题？

# 如何解决？

我并不知道。我只能说说的的观察和思考。

身边有一些朋友移民到了发达国家，日本、澳洲、法国。他们不约而同都提到了一个观点：**“革命工作只有分工不同，没有高低贵贱之分”。**

发达国家，把这样的口号，真正的落实了下去，而不是喊一喊而已。

能落实的根本原因之一在于：工资。**经济基础，决定上层建筑。**

你是高端编程工程师，出入5A写字楼，一个月赚10000，我去工地搬砖，虽然灰头土脸，但我也能赚7000。

虽然我们之间知识储备相差巨大，但是我们的收入差距并不悬殊。试想想，如果这样的社会，你还会逼迫你孩子去学习吗？

有一天，你承认了你的孩子确实不是学习的一块料，你就会这样想：算了，学一点技术，找一份工作也挺好，收入也不差能养活自己。

经济收入的缩小，就自然而然的会导致观念上的变化：人没有高低贵贱之分，只有分工不同。自然也就不会内卷了。

所以这从根本上来说，就两个字：公平。

不过呢，想要实现，要比登天还难。全世界将近有80亿人，发达国家人口只有10亿。

另外：总提公平是弱者的表现，这个世界本身就是不公平的。
