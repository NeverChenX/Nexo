# 2023遗嘱（2023-01-20）

Owner: Never

叔本华曾说：对于健康，要十分小心，因为身体哪怕有一处不健康的地方，就会吸引一个人的全部注意力，从而开始痛苦起来。

在写2022年的遗嘱时，更多的考虑，是能为这人世间的公平做出更多的贡献。而在去年生了一场大病之后，一个久病未愈的人，他的注意力只想拥有一个好身体。

当然，自己的内心，还是有一些大爱的存在，不过绝大部分如果有机会的话，还是想回馈下身边的人：自己的爱人、父母、兄弟姐妹。

今年得知，有一个同学得了尿毒症去世了，心中说不出的滋味，一个好端端的姑娘，正值人生的大好青春，却获得如此痛疾。农村老家的老人，接连患癌，就连自己的母亲也得了肿瘤，突然间我发现，我必须要开始更加认真的去面对死亡，脑海里也又开始涌现出那个经典死亡话题：

究竟怎样过完一生，到临终死亡时，自己才不会后悔？

对于自己来说，有两个层面来回答这个问题，分别是奋斗和享受。

# 关于奋斗

近几年来，我大概过的并不开心，我自己一直没有想明白原因。直到后来有一天，我终于听从朋友的建议，开始进行了冥想训练。

几天后，我突然顿悟到了自己不开心的根本原因：自己内心还有着一个非常远大的梦想（或者说是很大的欲望）。

而自己的努力却没有跟上，再加上年纪逐渐增大，导致身体状况越来越差，于是乎总想去逃避，总想去深山老林里，渡过余生。

一旦逃避的种子，在内心发芽后，就会开始疯狂的生长，直到开始迷惑人的心智，忘记自己内心真正追求的是什么。

另外还有一个辅助的原因，就是自己也快到了知天命的年纪，发现自己的天赋也就到这里了，那种眼望着目标就在眼前，但由于天赋有限却无能为力的绝望。

欲望之上是痛苦，欲望之下是享受。

不过，后来我想想，人终究还是要回归自己的内心，正视自己内心想要的东西，哪怕欲望很高，哪怕天赋有限，也要勇敢的去追求，并且付出极致的努力。

就像电影《集结号》一样，明知道敌人是自己的数倍，一旦开战有绝大概率会牺牲，你是否还有勇气上前线？

所以，真正考验人的不是顺境，而是逆境。

哪怕明知道自己天赋有限，也要直面自己内心的欲望，拼尽全力去努力。

唯有如此，才能在死前无悔的说：自己真的尽力了！

# 关于享受

看过一部电影《遗忘清单》，男主是一名维修工人，一生勤勤恳恳，获得脑癌后，开始列自己想要完成的清单。后来知道自己的时间为数不多，知道清单上的事项无法完成，于是愤怒的把清单揉成一团，扔进了纸篓里。后来，在同病房亿万富豪病友的帮助下，完成了自己的清单，无悔的离开了人生。

电影虽然感人，可我却有二个困惑：

1.为什么不在活着的时候就列遗忘清单，而却在自己快要死亡的时候才想着不留遗憾。（很多人都是如此）

2.如果男主的病友不是亿万富豪，那么清单上的事情注定无法完成，那么在死去的那一刻，人生岂不是满是懊悔？

所以后来我就想，我现在就要开始列遗忘清单，尽可能在活着的时候，就去做自己人生想要完成的事情。

这个清单，会持续的动态删减，以确保是自己在尽最大的努力活着。

这样，哪怕是自己立刻死亡，也不会留下任何遗憾，因为这是自己当前能想到的最佳的事情。

# 总结

在电视剧《庆余年》中，有一句台词非常打动我。监察院朱格勾结长公主暴露后，决定用匕首自行了断。

死前他说：我朱格一生为庆国，有憾但无悔。

我想，一个有憾而无悔的人生结局，已经足够幸福。
