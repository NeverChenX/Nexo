# 生孩子，对孩子来说公平吗？（史前文章）

Owner: Never

前几天，我看了一部电影《何以为家》，故事讲述的是：一个十二岁的男孩赞恩向法官状告他的亲生父母，原因是，赞恩的父母在无力抚养和教育的状况下依然不停生育，把他带到了这个世界上受尽苦难。

电影在这里就不过多赘述了，大家喜欢可以去看看。

不过，我看完了之后，却在我心里留下了个疑问：**生孩子，对孩子来说是公平的吗？**

如果生孩子，可以像秤砣一样可以衡量，那么在什么样的条件下，生育对孩子来说才算是公平的？

# **生育，一开始对孩子并不公平**

原因在于，在生孩子前，从来没有问过这个孩子要不要来到这个世界上，这样孩子从一开始就失去了选择权。

假设这样一个场景：

一个社会底层的印度贱民家庭，女人怀孕了。于是父母询问在肚子里的孩子：你即将出生在社会的最底层，将来有极大概率会成为文盲，每天过着像过街老鼠一样的生活，你确定你要来到这个世界上吗？

如果孩子答复：我确定。

将来某一天，孩子长大后质问父母：为什么我出生在这样的家庭？父母也可以有权利回怼说：当初是你自己选择要来到这个世界上的。

当然，这样的情况是不能发生的。

所以生育，对孩子来说，刚开始是居于劣势的，因为没有征求孩子的意见，就把他带到了这个世界上。

# **在什么样的条件下，对孩子来说才算是公平的？**

既然生育对孩子来说具有先天劣势，那后天又要靠什么样的弥补方式，才能够对孩子更加公平？

我总结出了三种养育方式。

## 1.能否负担起基本生活保障

如果单纯的以财富来衡量生育标准，很明显是有问题的。

有钱，不一定能够养育好，富人家庭的也有很多孩子，也有很多处于不开心中。而且，以这样的标准来去判断，穷人岂不是没有生孩子的权利了？

所以，这样的标准显然不行。

但如果不以财富来衡量，如果一个家庭穷的都吃不上饭了，却依然在坚持生孩子，那么对孩子其实也是非常不公平的。

所以，**财富的标准并不是要求上限，而是要求下限。**

**父母，至少要对孩子有生活保障，就算做合格，否则就是对孩子的不负责任。**

也许不能为孩子提供锦衣玉食，但至少可以为孩子提供健康的一日三餐；

也许不能为孩子上名牌私立学校，但至少可以提供上公立学校的机会；

也许不能为孩子拿出几十万治病，但至少可以花几万块钱为孩子买份保险；

...

所以，想要生孩子，一定要先去思考一下自己是否有能力做好孩子的基本保障？如果连吃的健康、受教育都非常困难，那对孩子来说是比较不公平的。

## 2.爱的独立，而不是利益交换

养“儿”防老，是这个世界上最恶心的经济行为之一，好在现在社会已经慢慢在改善这种现象。

这样的生育目的，本质上却是一种利益交换，这样父母与子女的关系会变得非常畸形。

这样的父母，自己会紧衣缩食，让孩子过上好生活，但并不是真正爱孩子(或者有部分爱)，真正的目的是，防止自己老年后，老有所依，老有所靠。

这样，慢慢演变成了一种思想：**年轻时的巨大付出，年老时要求巨大回报。**

典型的表现是，但凡子女有一点没有做到位，老人稍有不顺心，自己的内心就会觉得很“亏”，进而就会拿出“小时候一把屎一把尿把你拉扯大，结果我养了一群白眼狼”等孝顺主义之上的大旗，压的孩子喘不过气。

有一次，我的一个朋友的父母，从老家来看她。

她为了招待父母在家做了一桌子饭菜，结果因为时间关系，想让她父母自己在火车站打车过来。

可，就因为在家准备饭菜，没有时间去接她父母，导致她父母大发雷霆，各种骂她不孝。

如果说没有能力，或者人生地不熟也就算了，可她父母明明之前有来过，而且能熟练使用打车软件，却依然如此。

弄的我朋友非常愧疚，一度怀疑人生。

所以，我个人觉得一个人选择是否要生孩子，并不是以利益交换为目的，也并不是以传宗接代为目的，更不是因为自己无聊，想要孩子填充自己的生活。

而是，**让孩子体验一下这个精彩的世界为目的的生育，父母和子女之间也并不是“我养你小，你养我老”的强利益绑定关系，而是“彼此照顾好自己，中间以爱为链接的弱绑定关系”。**

所以，想要对孩子公平，就要反复的告诫孩子：你是一个独立的个体，跟父母之间不是利益交换。

所以不用为父母作出牺牲和让步。勇敢的去追求自己想要的生活，一旦在外面受到挫折，永远记住家里有一直爱你的父母，爱的港湾。

## 3.引导孩子找到人生的意义

在孩子未成年时，一般心性还未成熟，也没有见过这个世界真正的样子。

所以，很难知道自己想要什么。而作为父母，如果选择生孩子，就有义务去引导孩子去寻找自己人生的意义。

而不是，控制孩子的时间，去满足自己的一己私欲。

随便写两个例子。

有个朋友，从小一直在学习弹钢琴，可他父母从来都没有问过他是否喜欢钢琴，他父母的真正目的是：**逢年过节，自己的孩子在亲友面前弹一首钢琴曲，让自己特别有面子。**

相比来说，我就更苦了。

我从小在东北农村长大，每年秋天都需要帮家里干农活，最常见的农活是“扒苞米”。

我每年从小就要求“扒苞米”，一直干到我28岁时才停止。我曾经在深圳工作，每年国庆假期，我需要坐飞机回去帮父母干农活。

用收割机收玉米的费用是700块钱，我来回机票要3000，但我的父亲坚决不用收割机，因为觉得收割机弄不干净，祸害粮食。

包括我父母在内的，村子里的其他老人也一直认为：**父母干农活这么累，你帮忙就是孝顺，否则就是不孝顺。**

两个例子，有异曲同工之妙。都是利用道德绑架式，**强制性的让孩子过上了父母想要的生活**，但却从来没有考虑过孩子的感受。

所以，对孩子公平的做法是：多去发现孩子身上的闪光点，多陪伴孩子身边培养孩子某些天赋，引导孩子发现自己想要的生活，寻找到人生的意义。

人的一生，成长有着巨大的不确定性，所以父母不可能去控制孩子，让自己的孩子做提线木偶。

而是在孩子动态的一生成长中，做好教练的角色，不断鼓励孩子追求自己想要的人生。

这样的孩子长大以后才不会迷茫，才不会去每天早晨起来思考：上班的意义是什么，或者又是为了什么？

# **总结**

前一段时间，华为任正非的女儿姚安娜选择了出道娱乐圈。

很多人不理解，她千亿身价，为什么要去趟娱乐圈的浑水？任正非在采访时，给出了答案：

“她很努力，她很爱文艺，我的态度还是支持，不然未来其他路不顺，会觉得爸爸妈妈堵了这条路。”

所以，去尊重孩子的选择，远远比控制孩子选择，对孩子来说更加幸福。

而一句“我为你好”，压得一代人直不起腰。
